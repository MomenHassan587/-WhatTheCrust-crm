### defineProps

يعلن input اسمه name افتراضيًا car؛ الأب يقدر يمرر اسم من template.

- **بتاخد إيه؟ Inputs:** { name: { type:String, default:'car' } }

- **بترجع/بتغيّر إيه؟ Return / effect:** الـ props متاحة للقالب

### paths

- **بترجع/بتغيّر إيه؟ Return / effect:** array من strings؛ paths[name] || paths.car fallback

## وظيفة كل استدعاء في الملف — Methods & calls

نفس اسم method ممكن يظهر على objects مختلفة؛ اسم المستقبِل مهم. الـarguments الفعلية مكتوبة في السطر، والبطاقة تشرح العقد العام أو تعريف المشروع.

### defineProps

- **جاية منين؟** Vue compiler macro

- **وظيفتها:** يعلن المدخلات التي يبعتها المكوّن الأب؛ لا import داخل script setup.

- **المدخلات — Arguments:** runtime props definition أو type

- **الناتج/الأثر — Return / effect:** readonly props object

- **أول موضع هنا:** السطر 7، والمدخلات المكتوبة: `{ name: { type: String, default: 'car' } }`.

- **مثال:** const props = defineProps({ time: Number });

## جرّب تفهمه بنفسك

اختار function واحدة: حدد مين يناديها، الـarguments، كل return، وأول عنصر واجهة يقرأ نتيجتها. لو فيه حفظ/دفع/حذف، جرّب فقط في مشروع تدريب وبيئة آمنة؛ مجرد قراءة المصدر لا تحتاج تشغيله.

**English words:** Source = المصدر، Function = دالة، Parameter = اسم مدخل في التعريف، Argument = قيمة مبعوتة، Return = ناتج راجع، State = حالة، Side effect = أثر جانبي، Caller = الكود اللي نادى الدالة.
