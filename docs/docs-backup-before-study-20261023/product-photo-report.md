# Product photo report

The storefront and admin area use only local files from `public/images/menu/`. No images were downloaded from Talabat or any other website.

## Current photo setup

- Existing product files are WebP.
- Menu images use lazy loading and product-name alt text.
- Missing photos use the dark red branded `WTC` placeholder, with no emoji.
- New Admin Panel uploads are resized to a maximum width of 800 pixels and saved as WebP.
- Original files already in the folder were left untouched.
