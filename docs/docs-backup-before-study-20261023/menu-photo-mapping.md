## Duplicate source files

`canivora.png`, `pizza-cheese.png`, and `pizza-margherita.png` are byte-for-byte identical. The image shows a meat pizza, so it is not used for Margherita. `canivoraa.jpg` is also byte-for-byte identical to `canivora.jpg`. These originals were kept, but duplicates are not served by the menu.
